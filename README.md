# 🌐 Wi-Fi Brasil — Inclusão Digital

Um projeto web educativo sobre conectividade, acesso à internet e inclusão digital no Brasil.

## 📋 Sobre o Projeto

O **Wi-Fi Brasil — Inclusão Digital** é um site desenvolvido para apresentar a importância do acesso à internet e explicar como iniciativas de conectividade podem ampliar as oportunidades de acesso à informação e à educação.

O projeto utiliza como tema central o programa Wi-Fi Brasil, relacionado ao Ministério das Comunicações.

## 🎯 Objetivos

* Apresentar a importância da inclusão digital.
* Explicar o papel da conectividade no acesso à informação.
* Mostrar como iniciativas de internet podem beneficiar comunidades.
* Destacar os impactos sociais do acesso à tecnologia.

## 🚀 Conteúdo do Site

* **Início (`index.html`):** apresentação do Wi-Fi Brasil e de seus objetivos.
* **O Programa (`recondicionamento.html`):** página dedicada ao conteúdo do programa.
* **Conectividade (`inclusao.html`):** conteúdo relacionado ao acesso à internet.
* **Impacto Social (`impacto.html`):** apresentação dos efeitos sociais da inclusão digital.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** estruturação das páginas.
* **CSS3:** estilização e organização visual.
* **Imagens:** recursos visuais para complementar o conteúdo.

## 📁 Estrutura do Projeto

```text
sustentabilidade_semana/
├── css/
├── imagens/
├── index.html
├── recondicionamento.html
├── inclusao.html
└── impacto.html
```

## ▶️ Como Executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `index.html` no navegador.
3. Opcionalmente, utilize o Live Server para visualizar o site durante o desenvolvimento.

Mantenha as pastas de imagens e CSS organizadas conforme os caminhos utilizados no HTML.

## 🎓 Finalidade Educacional

O projeto foi desenvolvido para aplicar conhecimentos de desenvolvimento web enquanto aborda a importância da inclusão digital e da conectividade na sociedade.
